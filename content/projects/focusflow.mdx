title: FocusFlow
subtitle: "An AI study companion that breaks big, vague goals into focused sessions"
overview: "A web app where you type a fuzzy study goal and get back one focused session — a single suggested task and a timer — powered by the OpenAI API and a deliberately minimal interface."
why: "I kept knowing *what* to study but freezing on *how* to start. I wanted a tool that took a fuzzy goal and handed back a small, doable next session — so the hardest part, beginning, was already solved."
role: "Solo build — I shaped the idea, designed the flow, wrote the prompt logic against the OpenAI API, and built the front end in Next.js with AI coding tools as a pair."
learned: "Clarity beats feature density. Every time I added an option, the thing got worse. The best version did less — one suggestion, one timer, one next step."
nextStep: "Add gentle spaced-repetition nudges and a lightweight analytics view, but only if they can earn their place without cluttering that calm first screen."
