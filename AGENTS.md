# Personal Website Agent Guide

## Project Goal
This is Yun He's personal website. It should feel cinematic, modern, minimal, and personal. It is not a generic resume template.

## Tech Stack
- Next.js App Router
- TypeScript
- Tailwind CSS
- MDX
- Geist font
- Framer Motion only for meaningful interactions

## Design Direction
- Dark cinematic visual language
- High contrast typography
- Warm amber accent lights
- Minimal but memorable motion
- No heavy WebGL unless explicitly requested

## Pages
- Home
- Projects
- Writing
- Bookshelf
- About
- Contact

## Rules
- Do not rewrite the entire project unless asked.
- Prefer small, reviewable changes.
- Keep components reusable.
- Run build after changes.
- Report modified files and verification result.

## Done Definition
A task is done only when:
- The page renders correctly.
- TypeScript passes.
- Build passes.
- Mobile layout is checked.
- No unnecessary dependency is added.
